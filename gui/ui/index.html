Model providers

Paste an OpenRouter key to reach most models with one account. Keys are saved to (readable only by you); leave a field blank to keep the saved key or use the environment variable. ChatGPT (Codex login) reuses ~/.codex/auth.json from the Codex CLI.

Connections and environment

Exported to the agent's shell, one NAME=value per line. Examples: GH_TOKEN for GitHub, BRAVE_API_KEY for reliable web search, or any API key your research needs. Saved values show as dots; leave them to keep them.
